# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub
Security Advisory interface. Do not open a public issue containing a secret,
credential, private policy, complete session transcript, or raw run evidence.

If private reporting is unavailable, contact the repository owner through the
GitHub profile before sharing sensitive details.

## Evidence disclosure boundary

Only redacted reports, machine verdicts, and evidence hashes belong in this
public repository. Complete session and run evidence remains in the governed
internal evidence store. A hash proves identity of retained evidence; it does
not authorize disclosure of that evidence.

## Supported state

Security fixes apply to the current default branch and the latest frozen
protocol baseline. Historical frozen protocol files remain immutable; any
required clarification is recorded as a post-freeze note or a new protocol
version.
